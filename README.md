# MeuProjeto 🌐

Site pessoal desenvolvido para praticar HTML, CSS e JavaScript.

## 🚀 Tecnologias
- HTML5 semântico
- CSS3 (Flexbox, Grid, variáveis, animações)
- JavaScript (DOM, IntersectionObserver, localStorage)
- Google Fonts (Poppins)

## ✨ Funcionalidades
- Layout responsivo (mobile-first)
- Menu hambúrguer no mobile
- Modo escuro com persistência
- Animações de scroll reveal
- Formulário de contato com feedback
- Botão "voltar ao topo"
- SEO básico + Open Graph
